# VP8 decoder file list

Complete file list required to extract a standalone VP8 decoder from libvpx.

The lists below have been **verified by an actual build** using:

```
../configure --target=generic-gnu \
  --disable-vp9 --disable-vp8-encoder \
  --disable-postproc --disable-error-concealment --disable-multithread \
  --disable-spatial-resampling \
  --disable-examples --disable-tools --disable-docs \
  --enable-unit-tests --enable-debug
make -j28
```

Result: 47 codec object files, 537 unit tests pass.

---

## A. Source files (.c) that MUST be compiled (47 total)

These are exactly the `.o` files that ended up in the minimal VP8-decoder
build. Every one is mandatory; nothing else is.

### `vp8/decoder/` — VP8 decoder core (5)

```
dboolhuff.c           arithmetic / "bool" decoder
decodeframe.c         frame-level driver, header parsing
decodemv.c            mode + motion-vector parsing
detokenize.c          residual coefficient parsing
onyxd_if.c            decoder instance lifecycle (create/destroy/decode)
```

### `vp8/` — codec interface (1)

```
vp8_dx_iface.c        implements vpx_codec_iface_t for VP8 decode
```

### `vp8/common/` — encoder/decoder shared code (24)

```
alloccommon.c              buffer allocation
blockd.c                   macroblock descriptor helpers
dequantize.c               inverse quantization
entropy.c                  entropy coding tables
entropymode.c              mode probability tables
entropymv.c                MV probability tables
extend.c                   frame border extension
filter.c                   sub-pixel filter tables
findnearmv.c               motion-vector predictor search
generic/systemdependent.c  CPU detection hook (generic = no-op)
idct_blk.c                 IDCT block dispatch
idctllm.c                  4×4 IDCT (low/low math) kernel
loopfilter_filters.c       loop filter inner kernels
mbpitch.c                  per-MB pointer setup
modecont.c                 mode context tables
quant_common.c             quantizer tables
reconinter.c               inter-prediction reconstruction
reconintra.c               16×16 intra prediction
reconintra4x4.c            4×4 intra prediction
rtcd.c                     run-time CPU dispatch init
setupintrarecon.c          intra-prediction border init
swapyv12buffer.c           frame buffer swap helpers
treecoder.c                tree coder tables
vp8_loopfilter.c           loop filter top-level driver
```

### `vpx/src/` — public C API dispatcher (4)

```
vpx_codec.c           vpx_codec_*  generic dispatch
vpx_decoder.c         vpx_codec_dec_*  entry points
vpx_encoder.c         vpx_codec_enc_*  entry points (built unconditionally; no-op without an encoder)
vpx_image.c           vpx_img_*  image buffer helpers
```

### `vpx_dsp/` — DSP primitives (6)

```
bitreader.c             arithmetic decoder support for headers
bitreader_buffer.c      raw byte-aligned bitreader
intrapred.c             generic intra-predictor reference implementations (referenced via RTCD)
prob.c                  probability conversion helpers
skin_detection.c        skin-color block detector (compiled unconditionally, but unused by VP8 decode — see "drop list" below)
vpx_dsp_rtcd.c          RTCD init shim
```

### `vpx_mem/` (1)

```
vpx_mem.c               vpx_malloc/free wrappers
```

### `vpx_scale/` — YV12 frame-buffer mgmt (3)

```
generic/yv12config.c    YV12 alloc / config
generic/yv12extend.c    border extension on YV12 buffers
vpx_scale_rtcd.c        RTCD init shim
```

(With `--disable-spatial-resampling`, `generic/gen_scalers.c` and
`generic/vpx_scale.c` are not built.)

### `vpx_util/` (2)

```
vpx_thread.c            worker pool (built even with --disable-multithread; safely deletable in a fork)
vpx_write_yuv_frame.c   debug YUV dump helper (safely deletable in a fork)
```

### One more (1)

```
vpx_config.c            generated by ./configure — lists enabled features
```

## B. Header files required

These are the headers actually opened by the compiler during the
`vp8_only` build — extracted from the `.d` dependency files. Every
entry below was confirmed; nothing else from these directories is touched.

### `vp8/decoder/`

```
dboolhuff.h
decodemv.h
decoderthreading.h
detokenize.h
onyxd_int.h
treereader.h
```

(Drop `error_concealment.h` and `ec_types.h` unless `CONFIG_ERROR_CONCEALMENT=yes`.)

### `vp8/common/`

```
alloccommon.h              blockd.h                   coefupdateprobs.h
common.h                   default_coef_probs.h       entropy.h
entropymode.h              entropymv.h                extend.h
filter.h                   findnearmv.h               header.h
invtrans.h                 loopfilter.h               modecont.h
mv.h                       onyxc_int.h                onyxd.h
ppflags.h                  quant_common.h             reconinter.h
reconintra.h               reconintra4x4.h            setupintrarecon.h
swapyv12buffer.h           systemdependent.h          threading.h
treecoder.h                vp8_entropymodedata.h
```

29 files. `onyx.h`, `postproc.h`, `vp8_skin_detection.h` exist in the
directory but are NOT used by the decoder build.

### `vpx/`  (public API)

```
vp8.h            vp8dx.h
vpx_codec.h      vpx_decoder.h     vpx_encoder.h
vpx_ext_ratectrl.h               vpx_frame_buffer.h
vpx_image.h      vpx_integer.h    vpx_tpl.h
internal/vpx_codec_internal.h
```

11 files. **Note**: `vpx_ext_ratectrl.h` and `vpx_tpl.h` are needed even
in a pure decoder build, because `vpx_encoder.h` (which `vpx_codec_internal.h`
includes) transitively pulls them in. They are interface-only headers
(empty structs from the decoder's view) — small but mandatory.

Drop: `vp8cx.h`, `vp9*.h`, `internal/vpx_ratectrl_rtc.h`.

### `vpx_dsp/`

```
bitreader.h            bitreader_buffer.h
prob.h
skin_detection.h       (only because skin_detection.c is built)
vpx_dsp_common.h
vpx_filter.h
```

6 files. If you also delete `skin_detection.c` (as recommended below),
you can drop `skin_detection.h`. `variance.h` and `postproc.h` are NOT
needed (the doc previously claimed otherwise — `skin_detection.c/.h` in
fact only includes its own header).

### `vpx_mem/`

```
vpx_mem.h
include/vpx_mem_intrnl.h
```

### `vpx_scale/`

```
vpx_scale.h            yv12config.h
```

2 files. `vpx_scale.h` IS pulled in by `vp8/decoder/decodeframe.c` and
`vp8/decoder/onyxd_if.c` even with `--disable-spatial-resampling` — the
header guards arch-specific bits but is itself unconditionally included.

### `vpx_ports/` — platform glue

```
compiler_attributes.h
mem.h
system_state.h
vpx_once.h
vpx_timer.h
```

Only 5 files. The other headers in `vpx_ports/` (`arm.h`, `x86.h`,
`loongarch.h`, `mips.h`, `ppc.h`, `bitops.h`, `mem_ops*.h`,
`static_assert.h`, `asmdefs_mmi.h`, `emmintrin_compat.h`, plus the
`*_cpudetect.*` files) are referenced from arch-conditional `#if`
blocks that are not taken on `generic-gnu`. They can be deleted from
a single-arch fork.

### `vpx_util/`

```
endian_inl.h         vpx_pthread.h         vpx_thread.h
vpx_write_yuv_frame.h
```

4 files. `vpx_atomics.h`, `vpx_timestamp.h`, `vpx_debug_util.h`,
`loongson_intrinsics.h` exist in the directory but are NOT used by the
decoder build.

## C. Generated files

These are produced at configure/build time. You need either the generators
or pre-committed copies of the headers.

| File                        | Produced from                                  |
|-----------------------------|------------------------------------------------|
| `vpx_config.h`              | `./configure`                                  |
| `vpx_config.c`              | `./configure`                                  |
| `vpx_version.h`             | `./configure`                                  |
| `vpx_dsp_rtcd.h`            | `vpx_dsp/vpx_dsp_rtcd_defs.pl` + `build/make/rtcd.pl` |
| `vpx_scale_rtcd.h`          | `vpx_scale/vpx_scale_rtcd.pl` + `build/make/rtcd.pl`  |
| `vp8_rtcd.h`                | `vp8/common/rtcd_defs.pl` + `build/make/rtcd.pl`      |

For a single-arch fork you can pre-generate them once and check them in,
eliminating the Perl dependency at build time.

Alternative: write a small CMakeLists.txt or hand-rolled Makefile that
compiles the 47 .c files above and one of three configurations of
`vpx_config.h` (single arch, no SIMD, decoder-only).

```
tools/                                helper scripts

third_party/{nalloc,x86inc}/          unused once SIMD is gone
docs.mk, *.dox, mainpage.dox, keywords.dox
```

If you also accept the "compiled-but-unused" surprises listed in section A:

```
vpx_dsp/skin_detection.{c,h}
vpx_util/vpx_thread.{c,h}, vpx_pthread.h
vpx_util/vpx_write_yuv_frame.{c,h}
vpx/src/vpx_encoder.c
   (Note: vpx_encoder.h, vpx_ext_ratectrl.h, vpx_tpl.h cannot be deleted —
   they are pulled in transitively via vpx_codec_internal.h. Drop vpx_encoder.c
   only if you also stub the public encoder API in the .h.)
```

You can hand-delete these in a fork; the build system pulls them in
unconditionally, so just trimming the Makefile entries and `.c` files is
enough — the resulting `libvpx.a` will be a few KB smaller.
